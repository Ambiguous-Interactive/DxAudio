Data-driven sound effects and music for Unity, with no dependencies. Designers tune cues and tracks as assets; code calls one method. SfxPlayer.Play never allocates.

Docs · Quickstart · Editor tools · Changelog · Samples

30-second tour

[SerializeField] private SfxPlayer _sfx; [SerializeField] private MusicPlayer _music; [SerializeField] private MusicDuck _dialogueDuck; _sfx.Play("door"); // pooled, rate-limited, no repeats _music.PlayContext("level-1"); // crossfades in var lease = _music.Duck(_dialogueDuck, holder: this); _music.Release(lease); // composes with every other duck

What you get

Cues
Takes, pitch jitter, rate limit, priority, 3D falloff. All in an asset.
Voices
Fixed pool. Important cues steal; loops are never stolen.
Music
Contexts crossfade; returning resumes from where it was.
Ducks
Every live duck composes to the most restrictive mix.
