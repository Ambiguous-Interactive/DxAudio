Why teams use it

Assets, not code

Designers change volume, takes and falloff on the cue. Code calls Play.

Zero allocations

Play resolves voices and takes from pre-sized storage. CI checks it.

Ducks compose

Every live duck contributes; the most restrictive wins. No system overwrites another.

Editor visibility

See every voice, duck and fade while the game runs, in the Mix Monitor.
